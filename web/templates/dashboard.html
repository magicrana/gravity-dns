Device Configuration Guides

Zero VPN client installation instructions for all native operating systems.

🤖

Android 9+ (Private DNS)

Native DNS-over-TLS (:853)

  1. Open Settings → Network & Internet → Private DNS.
  2. Select Private DNS provider hostname.
  3. Enter user endpoint: <token>.{{.BaseDomain}}
  4. Tap Save. Geo-restricted traffic is transparently proxied!
🍏

Apple iOS / iPadOS / macOS

One-click .mobileconfig profile

  1. Go to Client Accounts tab → click View Setup for the user.
  2. Tap Download Profile (DoT).
  3. Open device Settings → tap Profile Downloaded → tap Install.
  4. iOS natively encrypts and routes all DNS queries through GravityDNS!
🪟

Windows 11 (DoH)

Native DNS-over-HTTPS (:8443)

  1. Open Settings → Network & Internet → Wi-Fi.
  2. Edit DNS server assignment to Manual.
  3. Set Preferred DNS IPv4 to: {{.PublicIPv4}}
  4. Select Encrypted only (DNS over HTTPS).
  5. Enter DoH Template: https://{{.BaseDomain}}:8443/dns-query/<token>
📺

Smart TV / Apple TV / Router

Stubby / dnscrypt-proxy / AdGuard Home

  1. On your home router or Apple TV, configure an upstream DoT client.
  2. Set upstream server to: {{.PublicIPv4}}:853 with TLS hostname: <token>.{{.BaseDomain}}
  3. All connected home devices now stream seamlessly!

WireGuard UDP Tunnel

VOIP & SIP TRUNK

Full Layer-3 UDP/TCP tunnel for VoIP softphones (Zoiper, Grandstream) and PBX (Asterisk, FreePBX, 3CX).

UDP :51820
Step 1: Run Server Provisioner

SSH into your Bangladesh VPS and launch the automated WireGuard manager:

sudo bash /opt/gravity-dns/scripts/setup-wireguard.sh

Auto-installs WireGuard, enables sysctl forwarding, sets NAT firewall rules, and creates peers.

Step 2: Connect Phone / PBX / Softphone
  • Android / iOS: Scan the QR code displayed in terminal using the WireGuard app.
  • Asterisk / FreePBX: Import the generated config from /etc/wireguard/clients/sip-trunk.conf.
  • Persistent Keepalive: Pre-set to 25s for reliable SIP NAT pinholes across Indian telecom carriers.
