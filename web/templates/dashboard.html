Device Configuration Guides

How to configure devices with zero VPN client installations.

🤖

Android (Private DNS)

Android 9+ native DNS-over-TLS

  1. Open device Settings → Network & Internet (or Connections).
  2. Tap Private DNS.
  3. Select Private DNS provider hostname.
  4. Enter user endpoint: <token>.{{.BaseDomain}}
  5. Tap Save. All apps now bypass geo-blocks automatically!
🍏

Apple iOS / iPadOS / macOS

One-click .mobileconfig profile

  1. Go to User Management tab and click Quick Setup for the user.
  2. Tap Download iOS Profile.
  3. Open device Settings → tap Profile Downloaded at the top.
  4. Tap Install in the top-right corner.
  5. iOS will natively encrypt and route DNS queries via GravityDNS!
🪟

Windows 11 (DoH)

Native DNS-over-HTTPS

  1. Open Settings → Network & Internet → Wi-Fi (or Ethernet).
  2. Click Hardware properties → edit DNS server assignment to Manual.
  3. Set Preferred DNS IPv4 to: {{.PublicIPv4}}
  4. Select Encrypted only (DNS over HTTPS).
  5. Enter DoH Template: https://{{.BaseDomain}}:8443/dns-query/<token>
📺

Smart TV / Apple TV / Router

DNS Proxy / Stubby / AdGuard Home

  1. On your home router or Apple TV, install or configure a DoT upstream client (e.g. Stubby, dnscrypt-proxy, or router native DoT).
  2. Set upstream server to: {{.PublicIPv4}}:853 with TLS hostname: <token>.{{.BaseDomain}}
  3. Now every device connected to your home Wi-Fi stream seamlessly!
